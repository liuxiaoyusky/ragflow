## 3. 问题根因分析

### Query Enhancement的负面影响

1. **关键词噪音**: 添加的关键词(如"yield", "equities", "fixed income")可能与预期chunk的关键词匹配度更低

2. **检索干扰**: 从scores数据看，部分Enhanced查询的`unwanted_avg`高于`wanted_avg`:
   - TC002 Enhanced: wanted_avg=0.41, unwanted_avg=0.45 (差距-8%)
   - 说明增强后反而更容易匹配到不相关的chunks

3. **中文关键词问题**: 添加的"惠理亚洲收益基金"等中文关键词可能在英文为主的文档中效果不佳

## 4. 改进建议

1. **精简关键词**: 只添加最核心的1-2个关键词，避免噪音
2. **去除中文翻译**: 文档是英文，不应添加中文关键词
3. **基于chunk标题匹配**: 使用section title作为关键词，而非泛化词汇
4. **考虑禁用Enhancement**: 当前数据显示Baseline更好
